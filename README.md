# తిమ్మరాజుపేట అభివృద్ధి వెబ్‌సైట్ — PDF-ఆధారిత ఫొటో వర్గీకరణ

ఈ సంచికలో 2021–2022, 2022–2023, 2024–2026 PDF డైరీలలోని ఫొటోలను తీసి, పేజీ వివరణల ఆధారంగా ఏడు విభాగాల్లో అమర్చాము. ప్రత్యేకంగా గుర్తించిన కొన్ని ఫొటోలకు పనుల పేర్లు ఇచ్చాము; ఇతర ఫొటోలకు సాధారణ విభాగం పేరు, PDF పేజీ సంఖ్య చూపించాము.

## GitHub Pages
`index.html` మరియు `images/` ఫోల్డర్‌ను రిపోజిటరీ root లో అప్లోడ్ చేసి Settings → Pages → Deploy from a branch → main / (root) ఎంచుకోండి.
